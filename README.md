## 📝 Project Description
**Proxy-DOS** is a functional web-based terminal simulator that blends vintage operating system history with modern utility access. It acts as an interactive front-end multi-boot console designed to look and feel exactly like a classic command-line operating system.

The project fulfills a dual purpose:
1. **Historical Exploration:** It serves as a portal to mount and inspect original, static assembly source files from iconic versions of computer history, including MS-DOS v1.25, v2.0, and v4.0.
2. **Custom Utility Launcher:** It hosts a custom-built layer called **UB DOS**. This specialized terminal environment strips away standard network limitations to function as a lightweight launchpad for your team's unblocked web tools, game indices, and deployment proxies.

By combining an old-school command prompt with dynamic modern APIs, Proxy-DOS transforms static code folders into an interactive hub for running network tools and testing unblocked development builds.
